# Задача: Сбор семантики и анализ конкурентов для abooking.org

## О проекте

**abooking** — CRM для частных мастеров (маникюр, массаж, репетиторство, фитнес и т.д.), работает как мини-приложение внутри Telegram. Ничего не надо скачивать — клиент открывает бот, а мастер управляет записями, рассылками, бонусами и отчётами прямо в Telegram.

- Сайт: https://abooking.org
- Бот: https://t.me/artisanbooking_bot
- Конкурентное преимущество: **всё внутри Telegram** (YCLIENTS, Dikidi и др. требуют отдельное приложение или сайт)

## География и языки

- **НЕ Россия** (Telegram там ограничен, аудитория сложная)
- **Целевые рынки:** Казахстан, Узбекистан, Украина, Грузия, Германия, Латвия, Эстония, Литва, Израиль, Кипр, Нидерланды
- **Два языка:** русский (основной) и английский (Европа, экспаты)

## Часть 1: Сбор семантического ядра

### Что это и зачем

Семантическое ядро — это список поисковых запросов, которые люди вводят в Google. Нам нужно знать, что именно ищут наши потенциальные клиенты, чтобы сделать страницы, которые Google покажет им в выдаче.

### Стартовые запросы (отправная точка)

Бери эти фразы и вводи их в инструменты ниже. Они дадут тебе расширенный список похожих запросов.

**Русские:**
- CRM для мастера
- CRM для частного мастера
- программа для записи клиентов
- запись клиентов онлайн
- напоминание клиентам о записи
- бонусная программа для салона
- CRM для мастера маникюра
- CRM для массажиста
- CRM для репетитора
- CRM для фитнес тренера
- Telegram бот для записи клиентов
- мини-приложение Telegram для бизнеса
- как вернуть клиентов мастеру
- учёт клиентов для мастера

**Английские:**

### Инструменты и как ими пользоваться

#### 1. Google Keyword Planner (основной)

- **Ссылка:** https://ads.google.com/home/tools/keyword-planner/
- **Нужен:** Google-аккаунт. Нажми "Начать" → создай аккаунт Google Ads (рекламу запускать не нужно, просто пропускай все шаги настройки кампании)
- **Как:**
  1. Открой "Найти новые ключевые слова"
  2. Вставь 3-5 запросов из списка выше
  3. **Важно:** выбери регион — Казахстан, Украина, Германия (НЕ Россию)
  4. Язык — Русский (для RU-запросов), English (для EN-запросов)
  5. Нажми "Показать результаты"
  6. Выгрузи в CSV (кнопка "Скачать" справа вверху)
- **Что нужно из результатов:** запрос, среднее число запросов в месяц, уровень конкуренции

#### 2. Ubersuggest (дополнительный)

- **Ссылка:** https://neilpatel.com/ubersuggest/
- **Бесплатно:** 3 запроса в день
- **Как:**
  1. Вбей запрос (например "CRM для мастера")
  2. Выбери регион (есть выбор страны)
  3. Скриншоть или копируй таблицу с результатами
- **Что нужно:** запрос, объём, SEO difficulty (SD), CPC

#### 3. ChatGPT (GPT-4) — для расширения

Вставь в ChatGPT этот промпт:

```
Я собираю семантическое ядро для SEO. Мой продукт — CRM для частных 
мастеров (маникюр, массаж, репетиторство, фитнес, клининг, фото и т.д.), 
работающая как мини-приложение в Telegram.

География: СНГ (кроме РФ) и русскоязычная Европа.

Вот мои стартовые запросы:
[вставь список выше]

Задача:
1. Расширь каждый кластер — добавь синонимы, длинные хвосты (long-tail), 
   вопросные запросы ("как...", "где...", "какой...")
2. Предложи кластеры, которые я мог пропустить
3. Раздели по намерению: информационные (ищет инфо), коммерческие 
   (сравнивает решения), транзакционные (готов попробовать)
4. Отдельно сделай то же самое для английских запросов

Формат: таблица — запрос | кластер | намерение | приоритет (высокий/средний/низкий)
```

### Формат результата

Собери всё в одну Google-таблицу с колонками:

| Запрос | Язык | Объём/мес | Конкуренция | Источник | Кластер | Намерение |
|--------|------|-----------|-------------|----------|---------|-----------|
| CRM для мастера маникюра | RU | 320 | Низкая | KW Planner | ниша-маникюр | коммерческий |
| appointment booking Telegram | EN | 110 | Низкая | Ubersuggest | telegram-бот | транзакционный |

## Часть 2: Анализ конкурентов

### Кого анализировать

| Конкурент | Сайт | Рынок | Зачем смотреть |
|-----------|------|-------|----------------|
| **YCLIENTS** | https://www.yclients.com | СНГ | Лидер, сильное SEO, страницы под ниши |
| **Dikidi** | https://dikidi.net | СНГ | Массовый, хорошие посадочные |
| **Altegio** | https://www.altegio.com | СНГ | Контент-маркетинг, блог |
| **Fresha** | https://www.fresha.com | Мир | Эталон англоязычного SEO |
| **Setmore** | https://www.setmore.com | Мир | Хороший EN-сайт, страницы по нишам |
| **Calendly** | https://calendly.com | Мир | Не прямой конкурент, но отличная структура |

### Что нужно собрать

#### А. Через Ubersuggest (бесплатно, 3 запроса/день)

1. Зайди на https://neilpatel.com/ubersuggest/
2. Вбей домен конкурента (например `yclients.com`)
3. Перейди в "Top Pages" (Топ страницы)
4. **Запиши топ-10 страниц** по estimated traffic
5. Для каждой страницы запиши:
   - URL страницы
   - Заголовок (`<title>`)
   - Примерный трафик
   - По каким запросам ранжируется

**Совет:** Ubersuggest даёт 3 бесплатных запроса в день. За 2 дня успеешь проверить все 6 конкурентов.

#### Б. Через ChatGPT (для анализа структуры)

Вставь в ChatGPT:

```
Зайди на сайт [yclients.com / dikidi.net / fresha.com] и проанализируй:

1. Структура сайта: есть ли отдельные страницы для разных профессий 
   (маникюр, барбер, массаж и т.д.)? Приведи примеры URL.
2. Как оформлены посадочные страницы: заголовок, подзаголовок, CTA, 
   есть ли отзывы, скриншоты, цены?
3. Есть ли блог? Какие темы покрывает?
4. Meta title и meta description главной страницы
5. Какой оффер на главной странице (бесплатный период, цена, демо)?

Формат: таблица сравнения по пунктам 1-5
```

#### В. Вручную (5 минут на конкурента)

Открой каждый сайт и запиши:
- Главный заголовок (H1 на главной)
- Подзаголовок
- CTA-кнопка (что написано)
- Есть ли страницы типа `/for/...` или `/industries/...`
- Есть ли блог

### Формат результата

Собери в ту же Google-таблицу на отдельном листе:

| Конкурент | Топ-страница | URL | Title | Трафик | Ключевые запросы |
|-----------|-------------|-----|-------|--------|-----------------|
| YCLIENTS | Для салонов красоты | /for/beauty | ... | 12K | CRM для салона |
| Fresha | For barbers | /for/barbers | ... | 8K | barber booking |

## Часть 3: Что делать с результатами

После сбора верни мне Google-таблицу (или Excel-файл) с двумя листами:

1. **Семантика** — все собранные запросы с объёмами и кластерами
2. **Конкуренты** — топ-страницы и их мета-теги

На основе этого я:
- Определю приоритетные запросы для первых страниц
- Спроектирую структуру сайта (какие страницы создавать)
- Напишу мета-теги и контент под конкретные запросы
- Сделаю версии на двух языках (RU + EN)

## Важные моменты

- **Регион:** всегда выбирай страны СНГ и Европу, НЕ Россию
- **Не фильтруй:** если запрос кажется странным, всё равно записывай — отсеем потом
- **Скриншоты приветствуются:** если не можешь экспортировать данные, скриншоть
- **Конкуренты ≠ враги:** мы не копируем их, а учимся на их SEO-структуре
